# 实体对象映射关系调整指南

## 一、数据流向规范

### 查询流向（读取操作）

```
数据库 → Entity(Model) → Dto → Resp → 客户端
              ↓            ↓
          Repository层   Service层
```

### 写入流向（写入操作）

```
客户端 → 各种VO(Sub等) → Req → Dto → Entity(Model) → 数据库
              ↓            ↓           ↓
          先转Req      Service层   Repository层
```

---

## 二、@AutoMapper 映射规则

| 对象类型 | 映射配置 | 说明 |
|---------|---------|------|
| **Entity (Model)** | `@AutoMapper(target = XxxDto.class)` | entity ↔ dto 双向（默认） |
| **Dto** | `@AutoMapper(target = XxxResp.class)` | dto → resp（查询返回） |
| **Param** | 无映射注解 | 删除原有的 `→ XxxReq` 映射 |
| **Req** | `@AutoMapper(target = XxxDto.class)` | req → dto（写入时） |
| **Sub** | `@AutoMapper(target = XxxReq.class)` | sub → req（各种VO先转req） |

---

## 三、具体调整步骤

### 1. Entity 文件（base-server/.../persistence/model/Xxx.java）

**调整前：**

```java
@AutoMappers({
        @AutoMapper(target = XxxDto.class),
        @AutoMapper(target = XxxParam.class)  // 删除此行
})
```

**调整后：**

```java
@AutoMapper(target = XxxDto.class)
```

**同时删除无用的 import：**

- `import com.xxx.api.param.XxxParam;`
- `import io.github.linpeilie.annotations.AutoMappers;`

---

### 2. Dto 文件（base-api/.../dto/XxxDto.java）

**调整前：**

```java
@AutoMappers({
        @AutoMapper(target = XxxResp.class),
        @AutoMapper(target = XxxSub.class)  // 删除此行
})
```

**调整后：**

```java
@AutoMapper(target = XxxResp.class)
```

**同时删除无用的 import：**

- `import com.xxx.api.request.XxxSub;`
- `import io.github.linpeilie.annotations.AutoMappers;`

---

### 3. Param 文件（base-api/.../param/XxxParam.java）

**调整前：**

```java
@AutoMapper(target = XxxReq.class)  // 删除此注解
public class XxxParam extends BasicParam {
```

**调整后：**

```java
public class XxxParam extends BasicParam {
```

**同时删除无用的 import：**

- `import com.xxx.api.request.XxxReq;`
- `import io.github.linpeilie.annotations.AutoMapper;`

---

### 4. Req 文件（base-api/.../request/XxxReq.java）

**调整前：**

```java
public class XxxReq extends XxxParam {
```

**调整后：**

```java
import com.xxx.api.dto.XxxDto;
import io.github.linpeilie.annotations.AutoMapper;

@AutoMapper(target = XxxDto.class)
public class XxxReq extends XxxParam {
```

---

### 5. Sub 文件（base-api/.../request/XxxSub.java）

**调整前：**

```java
public class XxxSub extends XxxDto {
```

**调整后：**

```java
import io.github.linpeilie.annotations.AutoMapper;

@AutoMapper(target = XxxReq.class)
public class XxxSub extends XxxDto {
```

## 四、调整后的完整映射关系图

```
┌─────────────────────────────────────────────────────────────────┐
│                         查询流向                                 │
│                                                                 │
│   Entity ←──────────→ Dto ──────────→ Resp                      │
│      ↑                  ↑               ↑                       │
│  @AutoMapper        @AutoMapper     (继承Dto)                   │
│  (target=Dto)      (target=Resp)                                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                         写入流向                                 │
│                                                                 │
│   Sub ──────────→ Req ──────────→ Dto ←──────────→ Entity       │
│    ↑               ↑                                  ↑         │
│ @AutoMapper    @AutoMapper                        @AutoMapper   │
│ (target=Req)   (target=Dto)                      (target=Dto)   │
└─────────────────────────────────────────────────────────────────┘
```

---

## 五、检查清单

- [ ] Entity：只保留 `@AutoMapper(target = XxxDto.class)`
- [ ] Dto：只保留 `@AutoMapper(target = XxxResp.class)`
- [ ] Param：删除所有 `@AutoMapper` 注解
- [ ] Req：添加 `@AutoMapper(target = XxxDto.class)`
- [ ] Sub：添加 `@AutoMapper(target = XxxReq.class)`
- [ ] 清理无用的 import 语句
- [ ] 编译验证无错误

---

## 六、注意事项

1. **继承关系保持不变**：
   - `Resp extends Dto`
   - `Req extends Param`
   - `Sub extends Dto`

2. **MapStruct Plus 的 @AutoMapper 默认是双向的**，所以 Entity 上只需配置一个指向 Dto 的映射即可实现双向转换。

3. **其他类似的 VO 对象**（如 `XxxEditReq`、`XxxAddReq` 等）也应遵循"先转 Req"的原则，添加 `@AutoMapper(target = XxxReq.class)`。

## 七、示例：Banner 模块调整结果

### Banner.java (Entity)

```java
@AutoMapper(target = BannerDto.class)
public class Banner extends BaseMyBatisPlusEntity<Banner> {
```

### BannerDto.java

```java
@AutoMapper(target = BannerResp.class)
public class BannerDto extends BaseDto {
```

### BannerParam.java

```java
// 无 @AutoMapper 注解
public class BannerParam extends BasicParam {
```

### BannerReq.java

```java
@AutoMapper(target = BannerDto.class)
public class BannerReq extends BannerParam {
```

### BannerSub.java

```java
@AutoMapper(target = BannerReq.class)
public class BannerSub extends BannerDto {
```
